# Scope audit

Check whether:

- intended application and audience are unambiguous;
- commissioner/funding/conflicts and review status are disclosed;
- functional unit captures equivalent performance, quality, lifetime, and use;
- reference flow and replacements are correctly calculated;
- boundary and exclusions are complete/symmetric;
- attributional/consequential/prospective approach matches the question;
- cutoff, allocation, recycling, biogenic carbon, and credits are defined;
- data-quality requirements and LCIA categories match intended use;
- public comparative/claim requirements are identified;
- scope changes are logged and propagated.

A technically correct model can still be invalid for the decision if scope is wrong.
