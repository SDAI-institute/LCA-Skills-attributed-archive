# Model audit procedure

## Trace a result backward

Select key categories and trace from headline result to method factor, elementary flow, process, provider, parameter, raw source, and functional scaling.

## Sample strategy

Audit 100% of:

- quantitative reference chain;
- top contributors and all credits;
- high-uncertainty/high-sensitivity parameters;
- direct emissions and co-products;
- manually modified datasets;
- unlinked/mapped flows;
- scenario overrides.

Use risk-based sampling for low-materiality background data.

## Recalculate

Independently recalculate at least:

- reference flow scaling;
- one process mass/energy/carbon balance;
- one allocation/substitution result;
- one direct emission factor;
- one LCIA characterization;
- one headline comparison/percentage.

## Software checks

Confirm active database/project, versions, IDs, product-system links/matrices, parameter sets, uncertainty settings, random seed, and frozen result. Re-run from a clean state where feasible.
