# Review orchestration

1. Select three to nine personas based on the risk map; always include methodologist and data/model integrity coverage for full studies.
2. Give every reviewer the same frozen study revision, goal, review purpose, materiality threshold, and output schema.
3. Run reviewers in isolated parallel contexts when supported. Otherwise run sequential passes without exposing prior findings until each pass is complete.
4. Merge by root cause and evidence, preserving the highest justified severity and all affected artifacts.
5. Remove duplicates and unsupported speculation. Keep disagreements as explicit reviewer questions.
6. Return a report-only findings set by default. The practitioner responds and applies changes.
7. Re-review corrected critical/major findings and any conclusion affected by the correction.

AI personas improve coverage but do not create legal independence or replace a qualified critical reviewer, verifier, program operator, toxicologist, ecologist, or sector specialist where required.
