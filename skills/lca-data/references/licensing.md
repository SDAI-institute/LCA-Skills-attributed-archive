# Data licensing and redistribution

LCA data access does not imply redistribution rights.

## Before use

Record provider, product/database, version, licensee, access method, permitted users, geographic/entity limits, transformation rights, publication rights, API restrictions, attribution, expiry, and confidentiality.

## Safe repository practice

- Store identifiers, metadata, mappings, and user-authored parameters when permitted.
- Do not commit proprietary unit-process inventories, characterization tables, credentials, or bulk exports.
- Do not reconstruct restricted databases from derived outputs.
- Share aggregate results only to the extent the license and program permit.
- Keep scripts parameterized so an authorized user can supply the database locally.
- Mark synthetic fixtures clearly; never disguise them as licensed data.

## Model exchange

An open format such as JSON-LD, ecoSpold, ILCD, CSV, or Excel does not override the source license. Check whether a recipient holds the required license before transferring a model with linked or embedded datasets.

## Standards

Standards are generally copyrighted. Encode operational summaries and checklists, not extensive verbatim standard text. Require the practitioner to access the legally obtained current edition for formal conformance.
