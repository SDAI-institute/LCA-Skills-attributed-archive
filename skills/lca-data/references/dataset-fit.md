# Dataset fit assessment

Score or narratively assess each candidate.

| Dimension | Questions |
|---|---|
| Product/function | Same reference product, quality, treatment service, or market function? |
| Technology | Same route, feedstock, efficiency, controls, scale, age? |
| Geography | Same grid, fuels, regulation, transport, water, land, suppliers? |
| Time | Data year and validity appropriate to study/reference year? |
| Unit/basis | Same mass/energy/volume basis, moisture, purity, LHV/HHV? |
| System model | Compatible allocation, waste, recycling, substitution logic? |
| Process role | Market, transformation, production mix, treatment, import, marginal supplier? |
| Completeness | Relevant inputs, emissions, infrastructure, waste, land, water included? |
| Data quality | Documentation, sample, uncertainty, review, representativeness? |
| License | Use, modification, collaboration, publication, redistribution permitted? |

## Proxy protocol

Document why the proxy is analogous, each mismatch, expected direction of bias, adjustment, uncertainty, and sensitivity case. Reject a proxy when mismatch affects the decision more than the expected alternative difference.
