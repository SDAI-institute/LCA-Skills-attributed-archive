# Program-rule compliance matrix

Create one row per material rule. Do not rely on memory.

| Field | Record |
|---|---|
| Program operator / authority | Name, jurisdiction, URL, contact |
| Program instruction | Identifier, version, publication/effective/expiry dates |
| PCR / PEFCR | Identifier, version, product category, CPC/UNSPSC/classification, validity |
| Standards | Applicable editions and amendments |
| Product definition | Product family, composition, technical performance |
| Unit | Functional/declared unit, reference flow, service life |
| Boundary | Required modules/stages, exclusions, capital goods |
| Data rules | Primary-data share, geography, age, supplier data, proxies |
| Cutoff | Threshold and cumulative completeness demonstration |
| Allocation | Hierarchy and prescribed factors |
| Recycling/EOL | Formula, rates, quality factors, credits, Module D or equivalent |
| Electricity | Supplier-specific, residual/market, location mix, losses, certificates |
| Biogenic carbon/LULUC | Uptake, storage, release, land-use change, separate indicators |
| LCIA | Method/version, indicators, characterization factors |
| Averaging | Site/product averaging and representativeness |
| Scenarios | Use, maintenance, replacement, transport, disposal assumptions |
| Reporting | Mandatory tables, units, significant figures, disclaimers |
| Verification | Reviewer qualification, independence, evidence package |
| Comparability | Conditions and prohibited claims |

For every row add `requirement`, `model implementation`, `evidence`, `status`, and `open issue`. Any unresolved mandatory row blocks release.
