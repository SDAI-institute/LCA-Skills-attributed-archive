# Sensitivity and scenario analysis

## Sensitivity types

- local one-at-a-time sensitivity for screening derivatives;
- range analysis for bounded parameters;
- global sensitivity for nonlinear/interacting models;
- discrete methodological sensitivity for allocation, recycling, LCIA method, system model;
- coherent scenarios for correlated technology, market, and future assumptions;
- break-even/threshold analysis for decisions.

## Priority

Test parameters that are high contribution, high uncertainty, decision-sensitive, or methodologically contested. Include reference flow/lifetime/performance, yield, capacity factor, energy source, recycled content, allocation, substitution, direct emissions, transport, use intensity, and end-of-life where relevant.

## Coherence

Do not combine every optimistic value in one alternative and every pessimistic value in the incumbent unless these are explicit bounding scenarios. Correlated assumptions should move together based on a narrative or model.

## Outputs

Report baseline, cases, absolute/relative change, ranking changes, decision threshold, and rationale. Tornado charts should use comparable parameter ranges and visible units.
