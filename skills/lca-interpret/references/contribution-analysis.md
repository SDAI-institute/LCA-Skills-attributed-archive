# Contribution and hotspot analysis

## Trace levels

Analyze at multiple levels:

1. life-cycle stage;
2. foreground process/unit operation;
3. background process/market;
4. elementary or technosphere exchange;
5. parameter/data source;
6. positive burden vs negative credit.

A database process contribution is not yet an actionable root cause. Trace to the emission/resource or upstream input causing the score.

## Cutoff and sign handling

Rank by absolute contribution as well as signed contribution. Negative credits can hide large positive burdens in net charts. Report cumulative coverage and “rest” so the displayed top contributors do not imply completeness.

## Actionability

Classify hotspots as:

- controllable foreground design/operation;
- supplier/procurement;
- use-behavior or lifetime;
- background scenario/policy;
- methodological artifact or credit;
- uncertain/data-improvement priority.

## Contribution stability

Repeat contribution analysis for relevant scenarios and methods. A hotspot that disappears under plausible choices is conditional; a persistent hotspot is robust.
