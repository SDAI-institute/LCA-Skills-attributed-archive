# Data quality requirements

## Dimensions

For material data define required and achieved:

- temporal representativeness;
- geographical representativeness;
- technological representativeness;
- completeness;
- precision/uncertainty;
- methodological consistency;
- reliability/source quality;
- sample size/variability where primary data exist.

## Primary-data plan

State which processes require supplier/facility data because they are decision-sensitive, dominant, novel, or poorly represented by databases. Provide collection periods, metering/allocation rules, QA, production normalization, and confidentiality treatment.

## Pedigree-style assessment

A pedigree score can help structure uncertainty, but it does not replace evidence. Record the rationale for each score and avoid converting ordinal judgments into precise distributions without an explicit model.

## Data gap rule

For each gap assign materiality and one of:

- collect primary data;
- use a named proxy plus sensitivity;
- bound with low/high cases;
- exclude with screening evidence;
- restrict the conclusion or study status.

## Comparison rule

Do not compare one system built from current primary data with another built from old generic proxies without testing the resulting data-quality asymmetry.
