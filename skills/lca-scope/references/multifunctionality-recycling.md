# Multifunctionality and recycling protocol

## Decision hierarchy

1. Avoid allocation by subdividing the process where physically/data feasible.
2. Expand the system or redefine function when it matches the decision and applicable rules.
3. Partition using an underlying physical/causal relationship.
4. Use another relationship such as economic value when justified and allowed.

Record the governing program/standard rule; do not choose the method that produces the preferred result.

## Partitioning checks

- Identify all valuable products and waste-treatment functions.
- Define allocation property, basis year, prices/physical properties, and normalization.
- Test price volatility or physical-key uncertainty.
