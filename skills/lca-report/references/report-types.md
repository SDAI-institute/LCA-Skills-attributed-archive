# Report types and proportionality

## Screening memo

Short, decision-oriented, visibly provisional. Include basis, boundary, proxies, method, range, hotspots, limitations, and next data needs.

## Internal technical report

Full enough for model maintenance and decision audit: protocol, inventory/data quality, versions, results, sensitivity/uncertainty, QA, and recommendations.

## Public LCA report

Complete methodology and limitations, external-review information where required, reproducibility within licenses/confidentiality, and claim controls.

## PCF/EPD/PEF package

Follow current standard/program/PCR/PEFCR templates and verification rules. Repository templates supplement but never replace program documents.

## Journal/research package

Methods sufficient to reproduce, code/data availability statement, scenario/model versioning, uncertainty, and supplemental inventory within legal/licensing constraints.
