# Full technical report content

1. Executive summary and status.
2. Commissioner, practitioner, funding/conflicts, review.
3. Goal and intended application/audience.
4. Product system and functional unit/reference flow.
5. Boundary, cutoffs, allocation, recycling, modeling approach.
6. Data collection and quality requirements/results.
7. Foreground model and engineering balances.
8. Background databases/system model and dataset modifications.
9. LCIA method/categories/version and special conventions.
10. Results by category and life-cycle stage.
11. Contribution/hotspot analysis.
12. Scenario, sensitivity, and uncertainty analysis.
13. Completeness, sensitivity, and consistency checks.
14. Conclusions, recommendations, limitations, prohibited uses.
15. Critical review/verification statement and responses.
16. Reproducibility manifest, source register, parameter list, and appendices.

Every result table requires functional basis, scenario, unit, method/category, rounding, and whether values include credits.
