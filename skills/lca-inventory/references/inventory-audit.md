# Inventory audit checklist

## Structure

- [ ] One quantitative reference per intended process product.
- [ ] Reference flow matches goal/scope.
- [ ] All exchanges have flow, amount, unit, direction, and provider/compartment.
- [ ] No ambiguous duplicate process/flow names.
- [ ] Foreground/background interface is documented.

## Physical integrity

- [ ] Mass and relevant elemental balances close.
- [ ] Energy basis and efficiencies are consistent.
- [ ] Yield, selectivity, recovery, losses, recycle, and purge reconcile.
- [ ] Capacity, uptime, lifetime, and annual scaling reconcile.
- [ ] Direct emissions and captured/waste fates are complete.

## Methodological integrity

- [ ] Allocation/substitution/recycling follows frozen protocol.
- [ ] Credits are feasible, unique, and separately visible.
- [ ] Cutoffs are screened for environmental relevance.
- [ ] Infrastructure/use/end-of-life are included or justified.
- [ ] Temporal/geographic/technology basis meets scope.

## Data integrity

- [ ] Source class and provenance are complete.
- [ ] Dataset versions/system models are consistent.
- [ ] Units and conversions are documented.
- [ ] Proxies have mismatch and sensitivity notes.
- [ ] Confidential/licensed data controls are respected.

## Software integrity

- [ ] No unlinked exchanges/providers.
- [ ] Signs and exchange types are correct.
- [ ] Product system/matrix was regenerated after changes.
- [ ] Baseline result is reproducible from frozen inputs.
