# Failure taxonomy

- `ENV`: executable, package, runtime, permissions, endpoint, authentication.
- `API`: protocol generation, schema, method signature, lifecycle, timeout, disposal.
- `ID`: wrong/duplicate UUID, activity, flow, category, provider, reference product.
- `UNIT`: dimension, conversion, flow property, sign, reference amount.
- `FORMULA`: parameter scope, stale formula, allocation factor, scenario override.
- `BALANCE`: mass, energy, carbon, element, water, charge, stock change.
- `METHOD`: boundary, multifunctionality, recycling, counterfactual, cutoff.
- `LCIA`: mapping, synonym, compartment, factor, region, method mixing.
- `NUM`: singular matrix, numerical artifact, failed stochastic iteration.
- `SYNC`: report/export/cache does not match active model/run.
- `EXPECT`: user expectation conflicts with model definition or evidence.

Assign one primary class and any contributing classes before correction.
