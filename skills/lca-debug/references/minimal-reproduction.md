# Minimal reproduction

A useful reproduction contains:

- exact version snapshot and start command;
- smallest non-confidential model or synthetic substitute;
- stable IDs, demand, method, parameters, and expected result;
- observed error/result and complete traceback/log;
- deterministic steps from clean state;
- evidence that the issue persists without unrelated data or scripts.

Never publish licensed datasets or confidential process values to demonstrate a bug. Replace them with synthetic values that preserve the failure mechanism.
