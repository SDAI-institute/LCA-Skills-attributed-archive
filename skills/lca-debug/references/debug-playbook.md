# Debug playbook

1. Freeze and hash the failure state.
2. Reproduce once with complete logging.
3. Verify environment and exact model/method IDs.
4. Reduce to one product system/activity, one scenario, and one indicator.
5. Inspect demand, technosphere, biosphere, then characterization in that order.
6. Test units/signs/reference products/provider links.
7. Check balances and formulas outside the LCA software.
8. Compare with a known-good fixture or alternate interface.
9. Correct one root cause and add a regression check.
10. Re-expand gradually; preserve any residual discrepancy.
