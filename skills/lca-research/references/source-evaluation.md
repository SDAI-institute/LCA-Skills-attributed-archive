# Source evaluation rubric

Score or narratively assess each candidate source.

## Dimensions

- **Authority:** issuer expertise, official status, peer review.
- **Directness:** supports the exact parameter or methodological claim.
- **Transparency:** boundary, methods, raw basis, equations, assumptions.
- **Technological fit:** chemistry, route, scale, equipment, product quality.
- **Geographic fit:** country/region, grid, regulation, climate, trade.
- **Temporal fit:** data year, operating period, future applicability.
