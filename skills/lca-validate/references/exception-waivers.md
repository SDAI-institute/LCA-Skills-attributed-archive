# Exception and waiver control

A waiver records ID, failed requirement, rationale, evidence, expected influence, affected results/claims, compensating control, owner, approver, expiry/review date, and status.

Never waive:

- undefined functional performance for a material comparison;
- unknown reference amount or result unit;
- unexplained conservation failure;
- unidentified model/database/method;
- unlawful data redistribution;
- missing independent review where the applicable public claim/program requires it.
