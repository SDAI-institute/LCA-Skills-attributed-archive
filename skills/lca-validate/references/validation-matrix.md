# Validation matrix

| Gate | Automated evidence | Expert evidence |
|---|---|---|
| Workspace | schema, required files, IDs, hashes | confidentiality and provenance fitness |
| Scope | required fields and status | functional equivalence and decision fit |
| Inventory | units, signs, duplicates, balances | process realism, completeness, counterfactuals |
| LCIA | method IDs, units, mapping coverage | category/method suitability and limitations |
| Results | totals, contributions, finite values | plausibility, hotspots, uncertainty, triangulation |
| Claims | phrase and authorization checks | audience, equivalence, review and trade-offs |
| Release | manifest, closed findings, reproducibility | intended-use readiness and independent-review status |

A passing syntax check is necessary but never sufficient for scientific release.
