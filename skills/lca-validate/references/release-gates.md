# Release gates

`PASS_INTERNAL` requires frozen scope, inventory QA, reproducible calculation, interpretation, and internal review appropriate to the decision.

`REVIEW_READY` additionally requires a review package, model access or transparent evidence, findings register, and practitioner response process.

`RELEASE_READY` requires all applicable program/verification/critical-review evidence, authorized claims, closed critical/major findings, release hashes, and confirmed redistribution rights.

The plugin cannot itself grant independent verification or certification.
