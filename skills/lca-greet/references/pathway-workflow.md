# GREET pathway workflow

1. Select exact release/platform/module and preserve baseline.
2. Identify product/fuel/vehicle/pathway and functional basis (MJ, kg, vehicle-mile, passenger-mile, tonne-mile, etc.).
3. Document boundary and stages included.
4. Inspect feedstock production, transport, conversion, distribution, use, vehicle/material cycle, and co-products.
5. Record user-editable input changes with original/default, new value, unit, source, and rationale.
6. Run baseline and coherent scenarios.
7. Export total and stage/process contributions.
8. Reconcile energy efficiency and carbon balance.
9. Audit co-product allocation/displacement and land-use change.
10. Compare to official example/training or independent result range.

Do not edit hidden/calculated values when a documented user input exists.
