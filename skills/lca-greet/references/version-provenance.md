# GREET version and provenance manifest

Record:

- model family/platform: R&D GREET .NET, Excel, or named module/tool;
- release name (e.g., 2025 Rev1), software version, database version;
- publication/release date and DOI where available;
- installation package checksum;
- pathway/entity identifiers;
- default/user input file or export;
- modified values and sources;
- simulation settings;
- output export and checksum;
- official update/known-issues page accessed date.

Do not label a result merely “GREET” because annual/revision updates can materially change defaults and pathways.
