# GREET troubleshooting

| Symptom | Checks |
|---|---|
| Result differs from publication | release/revision, platform, scenario year, input overrides, boundary, units |
| WTP/WTW confusion | stage selection, combustion/vehicle operation, functional basis |
| Unexpected negative pathway | co-product credit, waste baseline, biogenic carbon, land-use change, CCS |
| Huge hydrogen/electricity change | electricity mix, efficiency, compression/storage, capacity/utilization, GWP basis |
| Plugin failure | installed DLL/API version, plugin path/lifecycle, .NET/Windows requirements |
| Workbook result stale | calculation mode, macros, links, named inputs, recalc, version |
| Double count after integration | overlapping feedstock/energy/transport/use stages in host LCA |

Start from an unmodified baseline and reapply one change at a time.
