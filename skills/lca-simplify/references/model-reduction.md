# Model reduction methods

Use, in order of preference:

1. remove duplicate or unreachable model objects;
2. consolidate identical providers while preserving geography/technology distinctions;
3. parameterize repeated formulas and scenario deltas;
4. aggregate immaterial foreground steps only after contribution and uncertainty screening;
5. replace complex submodels with validated surrogates that preserve input/output behavior;
6. reduce scenarios using dominance and decision-relevance analysis;
7. archive—not erase—superseded artifacts.

Validate totals, hotspot rank, sensitivity, uncertainty, balances, and review trace after each reduction.
