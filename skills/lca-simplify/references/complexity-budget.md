# Complexity budget

Retain complexity when it materially affects:

- functional performance or reference flow;
- a hotspot, trade-off, constraint, or decision threshold;
- uncertainty or scenario ranking;
- program/PCR/standard requirements;
- reviewer reproducibility;
- future parameterization or maintenance.

Complexity has a cost: data demand, error surface, calculation time, review burden, and version drift. Record both the benefit and cost when retaining custom detail.
