# Change control

Classify changes:

- `editorial`: no model/result effect;
- `data`: value/source/uncertainty change;
- `structural`: process, boundary, provider, allocation, recycling, or mapping change;
- `method`: LCIA, characterization, normalization, weighting, or uncertainty method;
- `claim`: audience, comparison, or communication change.

Structural and method changes require a decision-log entry, affected-scenario analysis, recalculation, and review impact assessment. Data changes require provenance and sensitivity impact. Editorial changes still require report/model number synchronization checks.
