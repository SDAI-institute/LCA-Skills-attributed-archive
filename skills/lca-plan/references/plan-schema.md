# Plan schema

Each task must contain:

```text
ID | gate | objective | inputs | action | skill/tool | output artifact |
acceptance criteria | dependencies | owner | reviewer | stop condition | status
```

Use stable IDs such as `SCP-01`, `LCI-04`, `CAL-02`, `REV-03`. A task is not complete because prose was produced; its named artifact and acceptance evidence must exist.

The plan header records study/revision IDs, scope revision, model baseline, environment snapshot, assumptions inherited, risk tier, autonomy limits, and approval state.
