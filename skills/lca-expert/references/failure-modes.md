# Cross-cutting failure modes and anti-patterns

## Framing failures

- Starting from a database process rather than a decision and function.
- Treating `1 kg` as a functional unit without service/performance.
- Comparing different lifetimes, qualities, yields, payloads, or use conditions.
- Hiding exclusions behind “data unavailable.”
- Switching attributional/consequential logic mid-study.

## Inventory failures

- Broken reference product or production exchange.
- Unit conversions embedded in undocumented spreadsheet cells.
- Market and production datasets used interchangeably.
- Average grid used for a marginal policy claim.
- Direct emissions omitted because utility invoices were available.
- Capture/removal credit without energy, leakage, fate, permanence, or baseline.
- Burden-free waste/recyclate combined with avoided virgin credit.
- Infrastructure annualization inconsistent with lifetime/capacity factor.
- Allocating only burdens while assigning all co-product credit to the target.

## LCIA failures

- Method name reported without version/implementation.
- Mixed GWP assessment reports or time horizons.
- Climate-only result described as overall environmental performance.
- Unmapped flows silently ignored.
- Toxicity indicators described as actual risk or health cases.
- Water withdrawal treated as water-scarcity impact.
- Normalized/weighted single score reported without characterized results.

## Interpretation failures

- Hotspot equals largest database process without tracing underlying exchange.
- Monte Carlo used as a substitute for scenario/model uncertainty.
- Ranking claimed from overlapping or uncharacterized uncertainty.
- Negative result accepted because “system expansion” was selected.
- Sensitivity tests one parameter at a time despite correlated scenarios.
- Percentage improvement reported against a near-zero or inconsistent baseline.

## Tool failures

- Copying code from an incompatible version.
- Looking up entities by ambiguous names only.
- Mutating the only database/project copy.
- Failing to save allocation factors or reprocess matrices.
- Export/import interpreted as lossless without round-trip validation.
- Licensed data committed to source control.

## Reporting failures

- Headline number differs from frozen output.
- Review status omitted.
- Claims stronger than goal/scope.
- Gross burden and credits hidden in a net number.
- Limitations relegated to an inaccessible appendix.
