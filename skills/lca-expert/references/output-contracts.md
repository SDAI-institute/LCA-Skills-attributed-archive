# Output contracts

## Screening estimate

Must include purpose, declared basis, boundary, key proxies, method, result range, hotspot caveats, and a clear prohibition on external comparative claims.

## Internal decision LCA

Must include study protocol, traceable inventory, scenario/sensitivity analysis, data-quality assessment, QA findings, and decision thresholds.

## External technical study

Must include full methods, data provenance, versions, uncertainty, interpretation checks, limitations, reproducibility information, and review status.

## Public comparative assertion

Requires functionally equivalent alternatives, consistent rules/data/methods, full transparency, and appropriate independent critical review/panel according to applicable requirements. Do not release based on an internal agent review.

## Model handoff

Include:

- tool/project/database versions;
- model identifiers and reference product;
- parameter/scenario manifest;
- dataset/source register;
- calculation setup and result checksum;
- known issues and open findings;
- rebuild/run instructions;
- license constraints.
