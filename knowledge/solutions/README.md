# Validated LCA solutions

This directory stores reusable lessons captured by `/lca-compound` after a study issue has been resolved and validated.

Each entry should include:

- problem and context;
- observable symptoms;
- root cause;
- method or tool-specific fix;
- validation evidence;
- limits and non-applicable cases;
- source and software/database versions;
- prevention checks to add to future studies.

Do not store client-confidential information, licensed dataset rows, or unsupported conclusions here.
